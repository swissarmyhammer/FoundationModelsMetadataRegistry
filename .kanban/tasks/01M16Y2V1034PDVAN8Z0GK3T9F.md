## What

`DeterministicEmbedder` is the GPU-free `TextEmbedding` that replaces the live-Router embedder in every demo. It is public today, but it lives in one demo target: `Examples/HotReloadCore/HotReloadCore.swift:73`.

Move it to the shared `Examples/ExamplesSupport/` target so `SemanticSearchCore` can use it too. `ExamplesSupport` depends only on the main library target, so it stays GPU-free and Router-free.

Files to change:
- `Examples/ExamplesSupport/DeterministicEmbedder.swift` — new file. Move the type, its doc comment, and the `// MARK: - GPU-free deterministic embedder` section from `HotReloadCore.swift:63-...` unchanged.
- `Examples/HotReloadCore/HotReloadCore.swift` — delete the moved type. Add `import ExamplesSupport` if it is absent.
- `Tests/FoundationModelsMetadataRegistryTests/` — update any test that names `HotReloadCore.DeterministicEmbedder`.

Do not change the type's behavior. This is a move only.
